About the Project

Academic Intelligence is a Student 360 Data Platform designed to organize and analyze student information. It aims to provide meaningful academic insights and support data-driven decision-making.

Technology Stack

Apache Kafka Snowflake dbt Apache Airflow Python AI/ML Power BI

System Architecture

1. Data Streaming: Apache Kafka

2. Data Storage: Snowflake

3. Data Transformation: dbt

4. Workflow Management: Apache Airflow

5. Analytics: Power BI and AI/ML components

Project Objectives

  • Organize student academic information.
  • Build a data processing and analytics pipeline.
  • Generate meaningful academic insights.
  • Explore AI/ML applications for student analytics.
